# The values the code owns that a document or a comment has needed, read by `code_values`
# (tests/check_code_values.cmake; CONTRIBUTING.md#values-the-code-owns). A line registers one:
#
#   <id>  <owner file>  <symbol>
#
# The symbol is a `#define`, a constant (`S = v;`, `S{v}`), a `set(S v)`, or a quoted shape name
# whose version follows it (`"zen.Manifest", 5`). An id carrying `::` names the text's qualified
# spelling, for a name another file declares too. A value written without its owner's name is
# registered by how it is written, `{}` standing for the number:
#
#   claim   <id>  <spelling>   states the current value: every unmarked one is a copy
#   mention <id>  <spelling>   a copy at the current value unless it reads "since" or "and later"
#
# When review finds a value copied that this file does not know, it is registered here then.
